My Projects

1) Weather application

The Weather Application was one of the first full-stack projects I built during my first year. I developed a real-time working weather application which can be used to check the weather of any particular city or country. The application updates the information automatically when we search for a city, so there is no need to refresh the page. I used OpenWeatherAPI to retrieve real-time temperature, weather, humidity, wind speed and other basic condition details.

The technologies I used were:

  • HTML & CSS: Page layout and styling
  • Javascript: Fetching data from API and caching
  • PHP: Backend logic for data handling
  • MySQL: Storing weather data
  • OpenWeatherAPI: Live weather information

This project helped me understand the full-stack development functions in real time. It strengthened my foundation in web development and made me more confident working with APIs, database and general Javascript and CSS things.

2) Tic Tac Toe game

The Tic Tac toe game was also one of the first projects I built using Python during my first year. I built this Tic-Tac-Toe game in Python as a fun yet challenging way to learn how to structure a program, think logically, and break a game into clear, reusable functions. It started as a simple idea but quickly became a project where I could really test my problem solving skills and experiment with coding.

The technologies implemented were:

  • Python: Core programming language
  • Lists and Loops: For board representation and gameplay flow
  • Conditional statements: For game rules, win and draw selection
  • Functions: To make the code reusable, clean and easy to maintain

This project strengthened my programming fundamentals and taught me how to create a complete, interactive game using Python. It was an important stepping stone in my journey to more complex projects and this project helped me to develop a strong foundation and understanding of Python programming.
