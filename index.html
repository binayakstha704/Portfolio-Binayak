My Projects

1) Weather application

The Weather Application was one of the first full-stack projects I built during my first year. I developed a real-time working weather application which can be used to check the weather of any particular city or country. The application updates the information automatically when we search for a city, so there is no need to refresh the page. I used OpenWeatherAPI to retrieve real time temperature, weather, humidty, wind speed and other basic condition details.

The technologies I used were:

  • HTML & CSS: Page layout and styling
  • Javascript: Fetching data from API and caching
  • PHP: Backend logic for data handling
  • MySQL: Storing weather data
  • OpenWeatherAPI: Live weather information

This project helped me understand the full-stack development functions in real time. It strengthened my foundation in web development and made me more confident working with APIs, database and general Javascript and CSS things.

2) Tic tac toe game
